# Zdog TS

This is a TypeScript implementation of [Zdog](https://github.com/metafizzy/zdog).

It is modified with TypeScript support for bundler projects (Vite, Webpack, etc.)

## Installation

Install `zdog-ts` using your preferred package manager:

```bash
# Using npm
npm install zdog-ts

# Using yarn
yarn add zdog-ts

# Using pnpm
pnpm add zdog-ts

# Using bun
bun add zdog-ts
```

### CDN

This project is not intended to support CDNs. [Use Zdog on unpkg](https://github.com/metafizzy/zdog#cdn).

```html
<script src="https://unpkg.com/zdog@1/dist/zdog.dist.min.js"></script>
```
